How to host

One laptop runs the games and shows them on the TV. Players join on their phones over the same Wi-Fi. Setup takes about five minutes.

  1. Install Node.js

    On the laptop that will drive the TV, install the LTS version from nodejs.org. You only do this once.

  2. Download and unzip the games

    Use the download button above, then unzip it anywhere, like your Desktop.

  3. Start it

    In the unzipped folder, double-click start-mac.command on a Mac or start-windows.bat on Windows. On a Mac, if it's blocked, right-click it and choose Open. If Windows asks about the firewall, choose Allow. Keep the black window open while you play.

  4. Put it on the TV

    The big screen opens in your browser. Move that window to the TV and press Fullscreen.

  5. Players scan and join

    Everyone connects to the same Wi-Fi as the laptop, scans the QR code on the TV, and picks a name and icon. Then press Mix it up!

If something's off

Phones can't open the page

Some venue Wi-Fi keeps devices apart. Turn on a phone's personal hotspot, connect the laptop and players to it, then restart the games so the new address shows.

"Port is already in use"

The games are already running in another window. Close it and start again.

Someone's being silly

Click the ✕ next to their name in the lobby to remove them. Typed answers also pass through a family-friendly word filter.

Adding your own questions

Open content.json in the games folder with any text editor. Changes load the next time a game starts.
